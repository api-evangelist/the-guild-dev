# GraphQL Mesh Plans

GraphQL Mesh is an open-source project maintained by The Guild. It does not have its own standalone SaaS pricing tiers — the framework itself is free to use under the MIT license. The Guild offers enterprise support and consulting services, and their hosted platform (Hive Gateway) has separate commercial plans.

## Open Source (Free)

- **Cost:** Free (MIT License)
- **Source:** https://github.com/ardatan/graphql-mesh
- **Description:** Full access to the GraphQL Mesh framework for self-hosted deployments. Includes all handlers (REST, OpenAPI, gRPC, SOAP, OData, GraphQL, databases), transforms, caching, and federation capabilities.
- **Support:** Community support via GitHub Issues and Discord

## Hive Gateway (Cloud — The Guild)

GraphQL Mesh v1 integrates closely with Hive Gateway, The Guild's hosted gateway and schema registry platform. Pricing for Hive is published at https://the-guild.dev/graphql/hive/pricing.

### Hobby
- **Cost:** Free
- **Usage:** Limited schema pushes, operations, and observability
- **Support:** Community

### Pro
- **Cost:** Usage-based (see Hive pricing page for current rates)
- **Usage:** Higher operation volume, advanced observability, schema checks, CDN access
- **Support:** Email

### Enterprise
- **Cost:** Custom / negotiated
- **Usage:** Unlimited volume subject to contract, dedicated capacity, data residency options
- **Support:** Dedicated account management, 24/7 SLA, security review
