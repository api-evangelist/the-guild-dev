# GraphQL Tools Plans

GraphQL Tools is a fully open-source project maintained by The Guild. There are no commercial tiers or paid plans for the core tooling — all packages are available under the MIT license at no cost.

## Open Source (Free)

- All `@graphql-tools/*` npm packages
- Full access to schema building, stitching, merging, mocking, and transformation utilities
- Community support via GitHub Issues and Discussions
- MIT licensed — use in any project, commercial or otherwise

## The Guild Support & Consulting

While GraphQL Tools itself is free, The Guild offers paid professional services for teams that need expert assistance:

- **Architectural Review** — hands-on guidance for integrating GraphQL Tools into existing systems
- **Consulting & Workshops** — deep-dive sessions on schema stitching, federation migration, and API gateway design
- **Long-Term Support Contracts** — dedicated support and alignment with your organization's roadmap

For consulting and support inquiries, contact The Guild at https://the-guild.dev/contact.

## GraphQL Hive (Managed Platform)

For teams that want a managed GraphQL platform built on The Guild's tooling, GraphQL Hive offers commercial plans including schema registry, observability, and gateway features. See https://the-guild.dev/graphql/hive for Hive-specific pricing.
